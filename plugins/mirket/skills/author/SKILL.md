# Author

Deliver a document that its intended readers can use without this conversation. Use [Brief](../brief/SKILL.md) for transfer instructions to the next worker or session.

For bug reports or a QA backlog, use [issue triage](references/issue-triage.md). It owns intake, reproduction status, prioritization and issue drafts; use the steps below for general documents.

Keep intermediate files in `.work/temp/<task>/` under the [project workspace rules](../../references/workspace.md). Deliver the final document to its designated destination.

1. Establish the readers, what they need to know or do, the requested scope, and where the artifact belongs. For a revision, inspect the existing artifact and preserve unrelated content. Match the format to use when it is unspecified: Markdown for maintained repository guidance, a document for prose and collaboration, slides for a presentation, a spreadsheet for data or calculations, or PDF for a fixed layout. Follow the requested format and use the relevant format workflow and tools available in the host.
2. Structure the artifact around the reader's task. Ground material claims, figures, and instructions in the supplied sources or verified project evidence. Mark unresolved facts and assumptions; cite or link sources where readers need to check a claim. In a migration guide for support, for example, verify the steps against the current process and give readers the expected result and recovery path where those matter.
3. Check the final artifact in its intended format. Verify that links, instructions, and any calculations or totals work. For layout-sensitive output, open or render the final file and inspect the affected pages, slides, or sheets at readable size for clipping, breaks, and legibility. Text extraction cannot establish layout quality. If the necessary tool is unavailable, identify the missing check or format capability and state exactly what was produced.

**Done:** Return the document or its location, supporting sources where useful, and the material checks and limits. Deliver to the authorized destination; publishing or sending the document requires separate authorization.
