# Visual artifacts and assets

Use for static graphics, posters, banners, social images, presentations, identity applications, logos, icons and other visual deliverables. Follow the host's applicable artifact workflow for the requested file type.

## Start from use and output

Establish the message, audience, viewing distance, delivery channel, final format, dimensions and any print or platform constraints. Check current delivery specifications when the output depends on a third-party platform; do not assume dimensions, safe areas or compression rules are permanent. Ask for missing information that changes production.

Inventory approved logos, photography, copy, data, fonts and rights. Separate real material from placeholders and generated material. Use the proper generation or editing tool when requested and available. Never invent an endorsement, factual claim, logo permission or source attribution.

## Compose for the medium

Choose a focal point and a reading order that works at the intended scale. Balance type, image, whitespace and contrast according to the message, not an arbitrary text-to-image ratio. Use a consistent grid or alignment system where it helps. Check the composition at thumbnail and full size: the core message should remain legible when reduced, while edges and details should remain intentional when enlarged.

For a series, establish shared visual roles and allow individual pieces to adapt to their content. In a presentation, structure each page around the point it needs to communicate; check continuation, repeated headings, chart labels, notes and editability where relevant. In a banner or social crop, preserve the focal material and essential text inside the actual safe region.

## Logos and icons

For identity marks, establish intended use, reproduction contexts and existing brand constraints. Test recognition at small size and with reduced color where appropriate. For icons, keep meaning clear at the target size and match the existing set's geometry and weight. Prefer an editable vector when the required output calls for one; use raster imagery when it better fits the request. Do not imply trademark clearance or ownership merely because an asset was generated.

## Production and handoff

For print, confirm final dimensions, bleed, safe margins, color handling, resolution and supplier requirements before export. For digital delivery, consider density, crop, transparency, text readability and file weight. Preserve requested source files and editable layers when the workflow supports them. Give the final export and production conditions to [Critique](../../critique/SKILL.md) for rendered review; report any condition that could not be verified.
