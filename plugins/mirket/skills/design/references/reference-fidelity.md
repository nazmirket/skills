# Translate a visual reference

Use when reproducing a supplied screenshot or mockup in [Design](../SKILL.md), or implementing a generated reference from [Imagine](../../imagine/SKILL.md). Treat the chosen reference as the visual target. Establish which screen, viewport and state it represents; a single view cannot establish behavior or other layouts.

1. **Extract the visible design.** Map the section order, focal point, alignment and grid. Note relative widths, spacing and line wraps; type roles and weights; color roles and contrast; surfaces, borders and depth; media crop and placement; and control hierarchy. Reuse established assets and tokens where they produce the same relationships. Mark sampled or estimated values accordingly.
2. **Separate evidence from inference.** Transcribe readable copy as a reference; publish only supplied or verified copy, data and claims. Keep generated names, testimonials and metrics as labeled placeholders unless verified. Record what the image cannot tell you: exact fonts or assets, narrow layouts, hidden and interactive states, control behavior. Consult the original design file, existing product or a clearer authorized view if a gap changes the result. Otherwise infer from adjacent components and state the assumption.
3. **Translate with constraints.** Build semantic layout and working interactions with the actual product content. Follow the reference at its target size and use its hierarchy to guide reflow. Where fidelity conflicts with access, required behavior or real content, preserve those constraints and record the visible departure and reason. Avoid flattening the screen into a background image or replacing its distinct structure with a generic template.
4. **Request a comparable render.** Give [Critique](../../critique/SKILL.md) the reference and the target size, state and content, plus the evidence, inferences and departures. Start comparison at the matching viewport with comparable inputs, then cover relevant sizes and states the reference did not show. Critique owns actual inspection, findings and recheck. Distinguish a justified departure from a mismatch and report any comparison that could not be made.
