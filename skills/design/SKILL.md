# Design

Design owns visual artifacts and interface interactions. For creative work, agree on the intended effect and what the identity must preserve. Choose composition and treatment within that brief. Inspect the result in its intended medium.

**Every critique and visual check requires a verified, high-resolution capture of the complete reviewed surface.** Apply the [capture standard](references/tools/Screenshot.md). For web work, inspect the full page at the intended CSS viewport and at least 2× native density. Reuse matching verified originals. If coverage is incomplete, report what remains visually unverified.

| Requested result | Start here |
| --- | --- |
| New direction, artifact, interface concept or implementation from a visual target | [Create](references/flows/Create.md) |
| Compare visual or interaction approaches | [Prototype a comparison](references/flows/Create.md#compare-approaches-without-changing-production) |
| Change an existing interface's direction | [Redesign](references/flows/Redesign.md) |
| Improve an established direction or remove generic AI styling | [Polish](references/flows/Polish.md) |
| Critique a preview, export or interaction design | [Critique](references/flows/Critique.md) and the deliverable's format |
| Verify a specific interaction outcome, such as focus returning after Escape | [Check an interaction](references/flows/CollectEvidence.md#check-an-interaction) |
| Explain how to inspect or export with a named design tool | The matching [tool guide](references/tools/README.md) |
| Record observations about existing work | [Collect Evidence](references/flows/CollectEvidence.md) |
| Explain audience, intent or problem | [Understand](references/flows/Understand.md) |
| Agree what the design must achieve and preserve | [Author Brief](references/flows/AuthorBrief.md) |

Add a flow only for a distinct result. Use [formats](references/formats/README.md) for acceptance and handoff, [concepts](references/concepts/README.md) for craft, and [styles](references/styles/README.md) when choosing a treatment. Keep temporary evidence in the project's ignored scratch area and deliver requested artifacts to their designated destination.
