# Composition

Use to decide the hierarchy, grouping, focal point and reading order of a screen, asset, deck or frame.

## Design the structure before the surface

1. **Rank the material.** Put the primary proposition, action, relationship or subject where it can be understood first. Group supporting information by the questions it answers. Give every visible region a job; remove or defer regions without one.
2. **Choose a composition that fits.** A list suggests sequence, a table supports comparison, a continuous canvas supports reading, and a grid supports browsing equivalent items. Use alignment, grouping, scale and quiet space to create the eye path. A utilitarian screen may need dense rows; a single poster image may need room.
3. **Give emphasis selectively.** When everything is large, saturated, outlined or moving, nothing leads. Use contrast between important and supporting material. Keep the same hierarchy when the layout reflows.
4. **Place character where it pays off.** Choose a treatment grounded in the subject, such as an annotated close-up of a tool or a rhythm drawn from an illustrated story. Repeat its logic where it helps; keep familiar interactions and important content easy to recognize.
5. **Try it with the difficult material.** Use actual copy, the longest label, sparse and dense data, the narrow view or intended print size. Inspect the first useful slice before multiplying it.

## Use space to show relationships

For an event program or timetable, try the [International Typographic Style](../styles/InternationalTypographicStyle.md) specimen to test how a grid can establish priority across sizes.

Use proximity for belonging and larger intervals for transitions. Reuse a few spacing relationships where they help, and adjust for actual content and optical alignment. Establish clear edges and reading measure before refining margins or corner radii. A border can separate rows; a shadow can place a floating surface; a plain background can let the content carry its own boundaries. Avoid giving every group a container or every label a badge.

Choose density by task and device. Compact controls may serve repeated desktop operations, while touch actions and long-form reading need different spacing. Use separate layout treatments when one density rule would harm either.

## Bento box layout

Use modules of different sizes when items can be explored independently and vary in importance. Give the lead module space for real content or an action; size other modules for their job. Keep a sensible linear reading order at narrow widths. If people need sequence, row-by-row comparison or a single story, consider a list, table or continuous composition. Check uneven content and missing modules before committing to the grid.

## Check the combination

Look at the design in a normal case, an adverse case and one nearby existing surface when relevant. Hide decorative treatment briefly: if the hierarchy disappears, repair the underlying type, spacing or structure. Put it back when it adds useful atmosphere, emphasis or continuity. Check actual output rather than judging isolated swatches or components.
