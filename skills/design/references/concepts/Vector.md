# Vector artwork

Use for marks, diagrams, line art and assets that need clean scaling or editable shape geometry. [Vector Design](../formats/VectorDesign.md) covers a vector asset's fidelity, tracing and handoff.

## Build editable geometry

Set a useful artboard and view box. Use intentional paths, fills, strokes and joins. Prefer simpler geometry that preserves the silhouette and keep editable text or its source where required. Align critical edges by how they render at target scale; an enlarged canvas can hide fine-detail problems.

## Choose what scales

Choose whether strokes and spacing should scale with the form or stay visually stable at the target size. Simplify small silhouettes when full-size details merge. Keep groups and elements meaningful so editing one part doesn't require reconstructing the whole image.
