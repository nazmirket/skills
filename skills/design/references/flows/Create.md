# Create visual work

Use for a new direction, artifact or implementation of a supplied visual target. Start from the request, actual content and medium. A reference that changes an existing interface follows [Redesign](Redesign.md) for its live baseline and preservation rules. When the reference settles the direction, go straight to translation.

## Set the direction

Open the relevant [format](../formats/README.md) when the medium changes acceptance or handoff.

1. Identify the audience, intended effect, main action or idea, identity cues and constraints. Look for material only this project can supply, such as an object detail, a working screen, a route or a participant's own words. Check permission and accuracy. Mark gaps clearly. Use [Author Brief](AuthorBrief.md) for consequential open decisions.
2. If direction is open, show two or three approaches on the **same content**. Change the organizing idea, such as comparing alternatives in place or following one example in depth. For each, show what leads, how the eye reaches the next action, which material carries the identity and what gets less attention. Explain the tradeoff against the audience's task. Reuse prior agreement and take consequential choices to the human. The [style index](../styles/README.md) can help develop a fitting treatment.
3. Prove the consequential choice on a representative slice, including one awkward constraint such as a long title, a missing image or an unavailable action. Set type roles, grouping, density, image crop and emphasis there. Carry those relationships into the rest of the work. Use a [concept guide](../concepts/README.md) when a craft decision needs it.

## Generate an interface concept

- Inspect the product and authorized references. A redesign starts with the live baseline. Get explicit agreement on the audience, main action, hierarchy, content, visual direction, target views and constraints before generating. Reuse agreement on the same brief unless direction, scope or a material constraint changes.
- Generate the fewest views that answer the brief with an appropriate tool and approved inputs. Inspect the output against the brief, flag drift and placeholders, and show the direction. If the concept image is the deliverable, deliver it and stop.
- Implement a fitting concept only when the approved brief authorizes implementation. Ask before adopting a concept that changes direction or scope.

## Implement a supplied visual reference

- Identify the reference's viewport, content and state. Map section order, hierarchy, alignment, proportion, type roles, color, surfaces, imagery and crop. Preserve hierarchy, tone and relationships. Match requested literal details at the reference size first.
- Distinguish visible details from inferred values, unseen states, missing assets and unknown behavior. Use approved copy and assets. Label sample data. A static view establishes appearance at its captured state.
- Preserve semantic controls and access. Compare equivalent content, size and state, then test important alternate views and the real action. Record meaningful departures.

## Compare approaches without changing production

Name the uncertainty and the observation that would settle it. Build a small comparison with approved or synthetic data, isolated from production routes and writes. Show two or three labeled alternatives with the same representative content and states. Vary the decision under study. Make the switch keyboard operable and let the reviewer reset or replay each version from the same starting point. Return the runnable comparison, the observed tradeoff and remaining uncertainty. Adopt a direction in production only under separate authority.

## Finish

Deliver in the intended medium and existing stack. Carry the direction through the relevant states, formats and inputs. Inspect the result using [full-surface visual evidence](../tools/Screenshot.md). Follow initial inspection of substantial work with a distinct [critique](Critique.md) and recheck material corrections. Return the artifact or entry point, editable sources where useful and material limits.
