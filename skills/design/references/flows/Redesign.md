# Redesign an existing interface

Use when a materially different structure, direction or treatment is needed. Start with the affected path and requested effect. For a browser interface, use [Web Design](../formats/WebDesign.md) to identify relevant baseline and acceptance conditions.

1. Open the affected path in its browser or native runtime before designing. Capture [the full surface at high resolution](../tools/Screenshot.md) and observe important states, steps, sizes and inputs. Record the content, actions, destinations, field values, recovery behavior, access and identity cues that already work. Use [Collect Evidence](CollectEvidence.md) for deeper coverage. If live access is missing, stop the redesign at that specific blocker.
2. Agree on the intended effect and what may change. Identify an observed problem with a consequence, such as an offer whose actual terms are visible only after committing. Ask before changing working behavior, access, content meaning or distinctive identity unless already authorized. Use [Author Brief](AuthorBrief.md) if a shared record is needed.
3. Start with the project's material. For an open direction, use [Create](Create.md#set-the-direction) to compare materially different approaches on the same real content. Prove the riskiest change on a representative task. For a requested concept image, retain the baseline and follow the [generation agreement](Create.md#generate-an-interface-concept). For a supplied target, use [reference translation](Create.md#implement-a-supplied-visual-reference).
4. Develop the chosen approach in the existing stack through affected sizes, states and inputs. Use the [concept references](../concepts/README.md) for decisions that matter. Recapture the same cases and compare the whole surface and readable details. Revisit the original links, controls and failure or recovery path to distinguish deliberate departures from regressions.
5. Inspect the live result before delivery. For substantial work, run a distinct [critique](Critique.md) after initial inspection and recheck material corrections. Deliver the result, relevant editable sources, key departures and remaining limits.
