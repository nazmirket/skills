# Design formats

A format describes what a deliverable must include, preserve, and prove in its intended medium. Choose it after the requested workflow. It can apply to creation, redesign, and review without changing what any of those jobs authorizes.

## Interfaces and prototypes

| Result | Guide |
| --- | --- |
| A website, browser-based product surface, or web component in use | [Web Design](WebDesign.md) |
| A native or mobile-first task shaped by device behavior | [Mobile Design](MobileDesign.md) |
| An HTML file that someone opens independently of the product | [Standalone HTML](StandaloneHtml.md) |
| A component's isolated states, stories, or variants | [Component Preview](ComponentPreview.md) |

## Explanation and moving work

| Result | Guide |
| --- | --- |
| A talk, pitch, lesson, or deck for independent reading | [Presentation Design](PresentationDesign.md) |
| A diagram that explains relationships, sequence, or quantities | [Diagram Design](DiagramDesign.md) |
| An animation, motion asset, or distinct timed interaction | [Motion Design](MotionDesign.md) |
| An edited video, recording, or explainer with a timeline | [Video Design](VideoDesign.md) |

## Images, marks, and scenes

| Result | Guide |
| --- | --- |
| A wordmark, symbol, or logo variants | [Logo Design](LogoDesign.md) |
| An illustrated subject or a family of illustrations | [Illustration Design](IllustrationDesign.md) |
| A composed static artifact, such as a poster, cover, or handout | [Canvas Design](CanvasDesign.md) |
| A scalable or editable vector asset, including a trace | [Vector Design](VectorDesign.md) |
| Artwork produced by a rule system, or a reusable generator | [Generative Art](GenerativeArt.md) |
| A 3D still, asset, or interactive scene | [Scene Design](SceneDesign.md) |

Start with the requested result. A single deliverable can need a second guide when that adds a distinct check; a diagram delivered as independently opened HTML needs both correct relationships and the agreed portability. An ordinary local refinement can stay in its flow. Open only the craft or tools that settle a decision or collect evidence.
