# Design formats

A format describes what a deliverable must include, preserve, and prove in its intended medium. Choose it after the requested workflow. It can apply to creation, redesign, and review without changing what any of those jobs authorizes.

| Result | Guide |
| --- | --- |
| A website, browser-based product surface, or web component in use | [Web Design](WebDesign.md) |

An ordinary local refinement can stay in its flow. Open only the craft or tools that settle a decision or collect evidence the format needs.
