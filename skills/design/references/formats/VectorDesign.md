# Vector design

Use when editable or scalable geometry is the deliverable, including original linework or a vector reproduction of supplied raster artwork. [Vector](../concepts/Vector.md) covers shared path construction. Use [Logo Design](LogoDesign.md) or [Diagram Design](DiagramDesign.md) when identity or semantic accuracy supplies additional acceptance criteria.

## Choose the fidelity and structure

Agree on intended sizes, consumers, required editability and what must match. For a trace, distinguish a faithful reproduction from a deliberate simplification. Keep the original available for comparison, confirm permitted use, and identify what raster evidence cannot tell you. Do not infer precise dimensions or unseen geometry unless the task supplies that authority.

For original geometry, use editable groups, meaningful paths and purposeful joins. For reproduction, choose between tracing filled regions, preserving centerlines as strokes, and redrawing crucial curves or lettering. Inspect the result instead of assuming the tracing method handles both lines and filled shapes. Keep an editable source if the delivered version outlines text or expands strokes. If an export contains embedded raster material, disclose it when true vector geometry matters.

## Verify fidelity and portability

Open the vector in the intended viewer or editor and check bounds, stroke behavior, transparency, clipping and external dependencies. Inspect the smallest and largest requested placements. For tracing, compare the source and result at the same crop and scale; use an overlay when it reveals lost counters, broken joins or curve drift that a side-by-side misses. Check editability by selecting representative shapes or text in the receiving editor when it is part of the contract.

Return the requested file and editable original if different. Record which assets or fonts are required, what was simplified, and which effects or consumers remain unverified.
