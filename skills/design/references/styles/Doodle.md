# Doodle

Use informal hand-drawn marks to add a human voice, annotate real content or support a playful brief.

## Build the visual language

Give the marks a repeated line vocabulary, limited scale changes and clean spaces to interrupt. Attach important arrows or callouts to clear targets; allow decorative marks to stay quieter than the main subject.

## Avoid the cliché

Avoid visual clutter, ambiguous doodles as control icons and imitating handwritten text where fast reading is required. Distinguish a doodle's playful shorthand from the expressive construction lines in Sketch.

## Check it in use

Check the marks in context and remove some: the notes should help interpretation, and the remaining decoration should still feel coherent.

Annotate an actual assembly photograph with three original marks that point to distinct parts. Use the same line family and leave a clear endpoint on each target. Shrink the photograph and check that the marks still explain the assembly and leave its controls legible.
