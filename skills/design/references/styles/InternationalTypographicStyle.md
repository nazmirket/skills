# International Typographic Style

Use this direction when readers need to find details in a program, schedule or editorial layout. Study the relationship between type, image and unprinted space in Josef Müller-Brockmann’s Zürich concert poster. Identify the alignment that holds the material together and the contrast that determines where the eye enters. [MoMA concert poster](https://www.moma.org/collection/works/6257) · [Swiss National Library collection](https://www.nb.admin.ch/en/the-international-style-1950-1970)

Set an event name, date and venue on a shared grid. Give them different typographic roles and try an asymmetric arrangement with deliberate empty space. Recompose the same material at phone width. Verify the same facts are still easy to locate with the longest event name.
