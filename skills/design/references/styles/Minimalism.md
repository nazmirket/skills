# Minimalism

Use restraint when an object, action, or piece of information deserves undivided attention.

## Build the visual language

Make hierarchy with a small set of type roles, alignment, optical spacing and disciplined emphasis. Reserve ornament and color for a distinct job. Introduce enough material or typographic character to make the work recognizable.

## Avoid the cliché

Avoid stripping the labels, affordances or feedback users need. Empty space should group or focus the material; it should not force needless scrolling.

## Check it in use

Try a dense case as well as the ideal sparse one. Check that a first-time user still knows what can be done and how the sections relate.

In Donald Judd’s 1967 *Untitled*, the vertical space between units equals the height of a unit. Try giving a repeated element and its interval the same measure. Change just the interval and compare the grouping at the intended viewing distance. [MoMA collection object](https://www.moma.org/collection/works/81324/)
