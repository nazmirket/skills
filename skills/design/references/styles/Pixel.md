# Pixel style

Use a deliberate pixel grid for constrained illustration, retro game identity or a graphic system that depends on crisp sprites.

## Build the visual language

Set a base grid and draw clusters of pixels at that resolution. Use a limited palette, coherent lighting, readable silhouettes and integer scale where possible. Keep the pixel treatment distinct from longer reading text if readability needs a different tool.

## Avoid the cliché

Avoid mixed pixel sizes that make the grid feel accidental, blurry interpolation on intended hard edges, and detail that turns to noise at native size.

## Check it in use

Check at native size, a representative enlarged size and the host's actual scaling. For animation, inspect silhouettes and placement across frames.

Inspect a single symbol in Susan Kare’s *Graphic icon sketch* against its grid. Draw two versions of an icon for your own task, change one square at a time and compare which silhouette reads at native size. [MoMA icon sketch](https://www.moma.org/collection/works/188396)
