# Design styles

Open a style guide when the brief calls for a particular visual treatment or when comparing directions. Use it to make real decisions about hierarchy, material and character. Start with the project's identity and content; fit the style to what must remain recognizable and usable.

| Treatment | Choose it for |
| --- | --- |
| [Brutalism](Brutalism.md) | Raw structure and direct visual material |
| [Minimalism](Minimalism.md) | Selective emphasis and deliberate restraint |
| [Neo-Brutalism](NeoBrutalism.md) | Bold color, hard edges and playful physicality |
| [Glassmorphism](Glassmorphism.md) | Translucent depth with legible foreground layers |
| [Baroque](Baroque.md) | Dramatic direction, contrast and controlled ornament |
| [Ethereal](Ethereal.md) | Lightness and atmosphere |
| [Pixel](Pixel.md) | Crisp grid-built forms and sprites |
| [Sketch](Sketch.md) | Visible exploration and construction |
| [Bohemian](Bohemian.md) | Layered handwork, texture and mixed patterns |
| [Victorian](Victorian.md) | Period-informed typography, engraving and ornament |
| [Synthwave](Synthwave.md) | Retrofuturist darkness, perspective and glow |
| [Pop](Pop.md) | Decisive graphic contrast, repetition and saturation |
| [Doodle](Doodle.md) | Playful shorthand and hand-drawn annotation |
| [International Typographic Style](InternationalTypographicStyle.md) | Asymmetric grids and information hierarchy across a poster or program |
| [Ukiyo-e woodblock composition](UkiyoE.md) | Silhouette, depth and overlapping color shapes in an illustration |

For a modular Bento Box layout, use [Composition](../concepts/Composition.md#bento-box-layout). A layout pattern can work with several visual treatments.
