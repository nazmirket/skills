# Two-color print

Use a two-ink treatment when the work benefits from bold separations, paper and repeatable graphic shapes. Choose a dark ink for reading and a second ink for a specific relationship, such as the current event in a season. Allow the background stock to supply an additional value.

Compose in silhouette first. Use overprint or a coarse screen to add a middle value only where it clarifies the subject. Fine labels, schedules and functional UI need stable single-color edges. Keep any intentional misregistration in the illustration. On screen, verify text and controls against the actual background.

**Try it.** Set one workshop announcement in two inks with a large cut-paper tool, a date and an enrollment action. Print or preview it in grayscale, then crop it to the smallest placement. Check whether the tool, date and action still read in order once color contrast and edge detail are reduced.
