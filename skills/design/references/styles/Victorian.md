# Victorian

Use period-informed ornament and typography when the project has a historical, literary or craft connection. Pick a specific period and reference context if fidelity is promised.

## Build the visual language

Draw hierarchy from framed areas, engraved details, appropriate lettering and meaningful symmetry or stacked alignment. Let modern reading tasks use a clean measure even when titles and borders carry the period character.

## Avoid the cliché

Avoid equating all historical ornament with Victorian design. A fitting title and frame usually carry more identity than crowding the body with decoration.

## Check it in use

Inspect body copy, captions and fine linework at intended size and reproduction quality. Check whether the specifics match the claimed reference.

In the 1896 Kelmscott *Works of Geoffrey Chaucer*, compare the border, illustration and type on one spread. Give each a distinct visual weight in a new book layout, then check that readers can still locate the start of the text.
