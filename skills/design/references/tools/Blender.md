# Blender

Use when the deliverable is authored in Blender or when an asset needs a Blender-side inspection or export. Confirm the requested scene, consumer, Blender version and enabled features through the available app or approved automation. Keep the source file safe.

1. Inspect the intended scene, collection or selection before changing it. Check object transforms, scale, origin, linked data and the active camera or frame where relevant. Inspect externally linked resources; decide which stay relative or travel in the delivery, and verify that they can be found. Reopen a copy away from its source directories to catch missing resources.
2. When authorized to edit, preserve a working source and keep changes reversible where practical. Use a copy for applying modifiers, transforms or baking if they would change the editable source. Check only the relevant camera or material settings before rendering a representative frame.
3. Set export scope deliberately. Check the installed exporter’s options and record selection, axes, units or scale conversion, material handling and animation range as applicable.

Open the actual render or import the exported asset into its intended consumer. Check that textures and required properties survived; a Blender reimport is useful but cannot establish compatibility elsewhere. Hand over the editable file and dependencies when requested, plus export settings and proof or limits. If Blender is unavailable, inspect the supplied render or import with an authorized alternative and mark source edits or Blender-specific checks as unverified.
