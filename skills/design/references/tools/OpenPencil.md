# OpenPencil

Use for inspecting or editing an editable design document when OpenPencil is available and fits the requested outcome. Use the desktop editor or an available integration. Confirm whether operations target the live editor or a file on disk. Inspect the connected editor’s available operations before choosing an export or editing path.

1. Confirm the document, path, active page, and target frame or nodes before a read or write. Inspect the selected subtree and render the frame. Check fonts, components, and variable bindings when they could change what you see.
2. When editing is authorized, work on the agreed nodes. Use a named copy for an experiment or conversion. Keep edits scoped, render after a coherent group of changes, and verify the saved output path before overwriting any source.
3. For an image, SVG, or editable output, export the intended frame and reopen it. Check bounds, text, fills and meaningful effects. If handing a `.fig` back to Figma, preserve the original and verify the copy in the receiving editor before promising round-trip fidelity.

Report document and page, relevant node or frame, output paths, and differences you observed. If OpenPencil is unavailable, use another authorized viewer for the same evidence, or work from an approved export and mark editability and unverified document features as limits.
