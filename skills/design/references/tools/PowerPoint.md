# PowerPoint

Use when a PowerPoint deck is the source, editable deliverable, or intended playback environment. Confirm the exact file, target application, and requested outputs. Work on the agreed copy when editing is authorized.

1. Inspect the relevant slides in Normal view for editable objects, layout or master, notes and assets. Identify the slide size and fonts; check if content depends on media or links outside the file. Preserve the deck's existing layout system unless changing it is part of the request.
2. Play the actual deck in Slide Show for claims about viewing, transitions, builds, media or navigation. Inspect the affected slides at intended scale. Use the Reading Order pane where available to check the order and alternative text of meaningful objects and exclude purely decorative objects.
3. Reopen the saved deck and any requested export. Look for substituted fonts, moved or clipped objects, broken links, and missing notes or media where those are expected. Verify the PDF separately if requested; its appearance does not establish that the PowerPoint source remains editable or plays correctly.

Return the deck or export paths, the application used, and checked slide numbers. If only a compatible viewer or PDF is available, use it for the evidence it provides and report which PowerPoint-specific behavior remains unverified.
