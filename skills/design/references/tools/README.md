# Design tools

Use a tool guide for an operation the work actually needs. Prefer an available capability that can produce the required evidence. The workflow and format still decide what to inspect, what to change, and when to stop.

| Need | Guide |
| --- | --- |
| Open a web surface and inspect its real behavior or appearance | [Browser](Browser.md) |
| Replay a scoped browser path or collect a trace | [Playwright](Playwright.md) |
| Record a visible state from a page, app, or desktop | [Screenshot](Screenshot.md) |
