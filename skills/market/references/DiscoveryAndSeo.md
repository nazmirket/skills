# Discovery and SEO

Distinguish a visibility failure from an offer or content failure. Decide whether the job is to discover what people search and share, improve eligibility to be found, or make the result more helpful once found. Use Search when outside evidence changes the list of topics or channels.

- Match a topic to a real question and decision stage. Check actual search results, community discussions, and existing site evidence before assuming a keyword means an audience intent. Choose a format that answers the question well: comparison, guide, example, tool, or reference. Add original evidence where it improves the answer.
- For an existing page, check accessible response, robots behavior, index directives, canonical URL, relevant redirects, internal links, rendered text and sitemap coverage. Separate “technically eligible” from “observed indexed” and “ranking.” Structured data must represent visible content; it is not a guarantee of appearance.
- For scale, check that each page serves a distinct need with adequate material. Merge overlaps before adding more pages. Account for canonicalization and translated alternatives without treating locale or city substitutions as useful content by themselves.
- For editorial planning, prioritize audience usefulness, ability to prove the claim, distribution, and maintenance cost. Give each piece a reader, intended question, source material, next step, and review signal.

Report the most consequential issues with URL or condition, observed evidence, proposed fix and how to verify it. For a new program, return a small prioritized set and the signal that would justify expansion.
