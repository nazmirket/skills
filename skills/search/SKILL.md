# Search

Search owns read-only external research. [Adapt](../adapt/SKILL.md) establishes internal project facts. [Equip](../equip/SKILL.md) recommends a tool for the project.

## Find the signal

1. Define the question, whose activity matters and what would answer it. For recent trends, set a date range and look for change within it. For history, follow earlier names and accounts back to decisions or events in dated originals or archives.
2. Use broad search for leads, then search relevant threads, issue trackers, repository discussions, release histories or user forums directly. For technical claims, read the original specification, versioned docs or paper. Check versions, methods, comparisons and limitations. For competitors, inspect the public product or demo, docs and changelog, then look at users' experience in relevant threads, issues or forums.
3. Search again using practitioners' terms, names, links, workflows, workarounds or objections. Trace promising leads to their source and seek a credible counterexample. Use available access. If a venue is unavailable, try accessible sources that answer the same question and disclose weaker coverage. Keep private project details out of queries. Posting and outreach fall outside this workflow.
4. Open the source behind each material claim. Seek an independent signal for consequential claims. Count repeated coverage of one announcement once. Distinguish observed capabilities from promises, individual reports from patterns and visibility from adoption. Support trend claims with dated activity or comparable measures. When reports disagree, establish what each actually tested.

## Return what changes the picture

Lead with the finding and link directly to original threads, artifacts or records. Give dates where relevant. Distinguish observation from interpretation and surface material disagreement, thin evidence, coverage gaps and less obvious findings. Stop when further searching is unlikely to change the answer or the remaining gap is clear. Give the owner the evidence and its limits for the next decision.
